## Overview

ListenTrace reads system media sessions (same source as the control-center media player) and accumulates play time **on device only**.

**Privacy: local Room database only — no upload, no account, no analytics SDK.** Requires Notification Listener access.

## Build

Open in Android Studio (Android 8.0+), or `./gradlew :app:assembleDebug`.
